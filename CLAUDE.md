# Lebawi landing page

One static presentation page about Lebawi SMS for Lebawi International Academy's officials.
The app is in `Leulol/lebawi-sms`; this repository holds only the page. Read `README.md` first.

## Rules
- Plain HTML, CSS and one small JS file. No framework, no build step, no dependencies,
  nothing loaded from the internet (it must open from a USB stick).
- Short on purpose: the officials won't read long text. No implementation dates on the page.
- Claim only what the school has confirmed (README, "What the page may claim"); tag the rest
  "To confirm".
- Animate only transform and opacity; honour `prefers-reduced-motion`. All copy readable with JS off.
- Fictional demo data only in screenshots. The crest is the traced school crest; don't redraw it.
- Check phone width (no sideways scroll) and present mode (P) before pushing.
